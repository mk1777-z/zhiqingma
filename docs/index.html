About关于我

I'm a backend-focused software engineer. I'm currently pursuing an M.S. in Information Technology (Information Security) at Carnegie Mellon University, after earning my B.E. in Computer Science from Shanghai University.

At Huifu Payment I built production payment services in Java / Spring Cloud — idempotent order APIs, multi-currency withdrawals, fee settlement and ledger reconciliation. I care about correctness under concurrency, consistent ledgers, and systems that fail safely. I also have hands-on experience with blockchain systems (Hyperledger Fabric, Solana) and have co-authored two research papers in that space.

我是一名专注后端方向的软件工程师，目前在卡内基梅隆大学攻读信息技术（信息安全方向）硕士， 本科毕业于上海大学计算机科学与技术专业。

在汇付天下实习期间，我基于 Java / Spring Cloud 开发生产环境支付服务，包括幂等订单接口、多币种提现、 手续费结算与账务对账。我关注并发场景下的正确性、账务一致性以及系统的安全降级。 此外，我具备区块链系统（Hyperledger Fabric、Solana）的实践经验，并参与发表了两篇相关论文。
